# KFC 抖音素材复核工具

本地 Excel 核查工具。上传抖音 Offer 规划表和抖音后台商品明细后，选择需要复核的字段，工具按券 ID 生成核查结果。来源文件不会被修改。

## 启动

```bash
cd douyin_tool
./run_local.sh
```

打开 `http://127.0.0.1:8791`。

## 使用方法

1. 上传抖音 Offer 规划表，需含券 ID、产品名、活动价、L3、使用效期和上架时间。工具会汇总其中所有可识别的业务工作表。
2. 上传抖音后台商品明细，需含 `商品ID`、`商家平台券ID`。
3. 选择要核对的字段并生成结果表。

## 规则

- 结果按后台商品 ID 逐行输出，同一券 ID 下的多个商品不会合并。
- Offer 同券 ID 重复时，工具只在券名无 `【…】` 后缀的记录唯一时采用该记录，否则标为“待复核”。
- Offer 没有券 ID 时，仅在核心套餐名能够唯一匹配时回退比对。
- 商品类型以 Offer 产品名判断：包含“次卡”为“次卡”，其他为“团购”。
- 后台“每日可用时段”与 Offer“使用效期”中明确写出的时段比较；未写明时段时会标为“待复核”。

# KFC 美团素材复核工具

本地运行的 Excel 核对工具：上传 KFC 总表和美团后台导表，选择需核对的字段后，按美团券 ID 自动生成结果。无需 API、登录或店小助；上传的来源文件不会被修改。

## 启动

```bash
cd meituan_tool
./run_local.sh
```

打开 `http://127.0.0.1:8790`。

## 使用方法

1. 上传 KFC 总表。可以是单工作表总表，也可以是含多个历史业务工作表的常用表；工具会按与后台券 ID 的重合数量自动选择最合适的工作表。
2. 上传美团后台导表（需要有 `商家商品id`）。
3. 勾选核对字段：售卖开始/结束时间、项目名称、使用有效期、规则说明、美团价、原价、菜品备注，以及“原价/美团价”公式校验（共 9 项）。
4. 下载 `美团审核结果表.xlsx`。

## 结果说明

结果工作表为 `核查结果`。每个券 ID 一行，显示 KFC 总表值、美团后台值、字段结论、整券结论和异常原因。

- `通过`：两边字段可读取且一致。
- `待复核`：缺少记录、同券 ID 多行字段冲突、字段为空，或 offer 表券 ID 为空只能形成候选关联。
- `不通过`：同券 ID 下两边字段值明确不一致。

工具支持 `券ID`、`优惠券ID`、`商家平台券ID`、`美团券ID`、`券码` 等常见列名，并会在前 30 行自动寻找表头。
